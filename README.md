# 私募基金运营管理研习手册 · FundOps Handbook

一本可以离线阅读、做题和记笔记的基金运营研习手册，覆盖法规、业务流程、组织管理与持续改进。适合希望系统理解基金运营、承担流程管理职责，或拓展跨岗位知识的读者。

手册以私募基金为主，将知识讲解、教学案例、情景测验和工作模板结合起来，帮助你理解业务如何运作、控制为什么存在，以及如何组织团队完成交付。

## 下载与开始使用

**[下载 HTML 或完整离线包](https://github.com/fundops-notes/private-fund-operations-handbook/releases/latest)**

1. 在下载页的 **Assets** 中选择 `fundops-handbook.html`，或下载 `fundops-handbook-offline.zip` 并解压。
2. 用 Edge 或 Chrome 打开 HTML，即可阅读、做题和记录笔记，无需部署服务器或安装依赖。
3. 首次使用建议从“学习路径”开始；查找具体业务用“实务知识树”，查阅条文用“法规原文库”。

正文与练习可离线使用，打开外部权威来源链接需要联网。

## 你可以在这里学什么

### 基金运营实务

实务知识树按 11 个分支组织 27 篇专题。每篇说明业务目的、适用范围、操作流程、关键控制与异常处理，并配有案例、自测和底稿字段。

| 知识分支 | 主要内容 |
| --- | --- |
| 业务、主体与责任 | 管理人、托管人与服务商分工，产品生命周期与参数管理 |
| 估值与基金会计 FA | 估值政策、资产类别、NAV 生产、费用与净值差错 |
| 注册登记与投资者服务 TA | 开户、申赎确认、份额事件、接口与回执 |
| 交易后运营与资金管理 MO | 交易确认、清算交收、现金与保证金、上海黄金交易所业务阅读 |
| 监管报送与信息披露 | 义务清单、报送日历、字段口径、跨表勾稽与更正 |
| 跨境运营与涉税信息 | QDLP、FATCA、CRS 的流程与判断框架 |
| 风险控制与外包管理 | 独立验证、服务商监督、退出与业务连续性 |

| 案例、练习与工作模板 | 将知识转为可记录、可复核的工作底稿 |
| 公募专项入门 | 识别公募与私募的制度和接口差异 |

### 组织与管理

从八个框架学习监督、授权、团队学习与改变：委托代理、Galbraith 星型模型、有限理性、RAPID 与职责矩阵、心理安全、双环学习、PDSA 和 Kotter 变革管理。

理论讲解配合八个管理案例，讨论“改了组织图，交付为什么仍然晚”“零差错报告是否代表没有风险”“新流程发布后，团队为什么仍用旧表”等问题。阅读案例背景与分析后，通过测验检验行动选择和适用边界。

### 法规原文与解读

法规库收录 21 篇正文、1,381 条条文和 50 条重点解读，可按层级、基金范围和关键词检索。桌面端左右对照原文与解读，手机端上下阅读；关联条文支持本地跳转，来源链接保留在正文末尾。

实务资料另提供 18 张权威来源卡片，包括估值、会计核算、技术接口与跨境税务等阅读入口。法规正文、行业参考、推荐性标准、地方试点资料和征求意见稿分别标识。

## 怎样学习与练习

24 个基础单元提供四周建议路径，可以按顺序学习，也可以自由跳读。单元和专题按“知识讲解—教学案例—应用与测验”组织，篇首目录支持章节跳转，参考资料与模板在文末展开。

手册共有 51 道测验题：24 道在“情景练习”中，可按知识单元筛选；27 道分布在实务专题中。选择答案后显示解析，可以反复练习。完成标记、收藏和笔记帮助你安排后续复习。

27 组底稿字段清单支持单独或批量下载，可用于梳理责任、参数、差异、证据与验收记录。模板提供工作结构，使用时需结合具体业务细化。

## 学习记录与备份

进度和笔记保存在浏览器本机，不会自动上传至 GitHub，也不会跨设备同步。

- 基础单元：在“我的笔记”导出学习进度 JSON 和笔记。
- 实务专题：在“实务知识树”导出实务进度与笔记。

两类记录分别备份和导入。更换设备、浏览器、移动文件或下载新版本前，建议先导出备份。请勿录入未获授权的机构或投资者信息。

## 内容范围与使用说明

本手册为通用研习材料，案例和计算示例均为虚构。解读与操作建议不等于法规原文或机构批准的 SOP；实际执行需结合主体、产品、有效规则、合同和授权。

资料按各篇标注的核验日期使用，页面不自动更新。历史汇编不代表最新完整规则，征求意见稿不作为已生效义务。公募部分为差异识别入门，地方 QDLP 资料仅作地方示例，具体产品操作与生产接口仍需查阅适用文件。
