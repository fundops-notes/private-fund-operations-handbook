# 私募基金运营管理研习手册

一份可下载、离线使用的交互式研习手册，围绕私募基金运营实务、法规阅读和组织管理，帮助读者把知识转化为判断、控制和行动。

## 下载与使用

进入本仓库 **[最新版本下载](https://github.com/fundops-notes/private-fund-operations-handbook/releases/latest)**，在最新版本的 **Assets** 中下载：

- **HTML**：一个文件即可使用。下载后用 Edge 或 Chrome 打开，无需安装或启动服务器。
- **离线包 ZIP**：包含相同HTML、使用说明和权威来源索引，解压后打开HTML。

两者任选其一。正文、解读、案例与练习可离线使用；点击外部来源链接时需要联网。请下载发布附件，不必下载自动生成的 Source code 压缩包。

## 版本与覆盖范围

首版内容核验日期：**2026-09-23**。页面不会自动更新，请关注后续Release。

法规正文来自发布机关、协会或政府部门的权威转载，每条阅读页末尾保留来源链接。PDF文字经过页码清理与换行重排；正文和编写者的解读分别展示。关联链接用于共同阅读，不当然表示法规之间相互援引。

本版是核心研习库，不是全部适用规则的穷尽清单。《私募证券投资基金运作指引》正文、部分登记配套指引、合同与披露模板尚未内嵌，已在扩展索引标明并保留权威入口。会计税务、交易所结算、跨境和专项试点等应按实际业务补充。并非所有条文均有专题解读。

内容为通用研习材料，不代表任何机构的实际制度；案例均为教学虚构情景。实际工作中需核对现行规则、机构角色、基金类型及有效合同。

## 学习记录

进度和笔记保存在当前浏览器本机，不上传至GitHub，也不自动跨设备同步。换浏览器、移动HTML或更新版本前，请在「我的笔记」导出JSON备份，再在新版本导入。支持原版学习进度备份。

当前提供下载使用；尚未为原创代码和讲解指定开放许可。第三方资料与法规来源单独标示，不因本仓库发布而重新授权。
