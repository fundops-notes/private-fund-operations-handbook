# 私募基金运营管理研习手册 · FundOps Handbook

可下载的离线互动知识库：法规原文、运营实务、组织管理与练习。内容为通用研习编写，案例和计算示例均为虚构。

## 下载使用

[最新版本与附件](https://github.com/fundops-notes/private-fund-operations-handbook/releases/latest)

下载 fundops-handbook.html 用 Edge 或 Chrome 打开，或下载 fundops-handbook-offline.zip 解压。无需服务器。正文与练习可离线使用，访问权威来源需要联网。

## 版本与适用边界

新增资料核验日期为2026-10-03，原法规核验日期仍逐篇保留，不宣称全库已重新完成现行性审查。页面不自动更新。

法规与原创解读分开展示。来源包括权威发布机关和权威转载。行业参考、技术标准、地方试点和征求意见稿分别标识。2017估值汇编不是最新完整规则集；2026募集征求意见稿不是已生效义务。

公募目前为差异识别入门；ETF/LOF逐产品操作和具体生产接口待深化。地方QDLP资料只作地方示例。各市场规则、税务、会计方法与业务适用范围应结合实际主体、产品、有效规则和合同核对。
