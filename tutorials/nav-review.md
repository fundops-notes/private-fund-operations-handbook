# 做一份能够解释的 NAV 复核底稿

人民币、单一份额类别、简单股票和债券持仓；无税费、汇率、业绩报酬或本期申赎。以下金额、价格、费率和截止口径全部为教学假设，不代表真实基金政策。

目标：一份NAV重算表、一张差异登记表、一段发布前复核意见。

准备：了解资产、负债、净资产和份额的关系；可先阅读“FA：解释一张净值表”。使用计算器或自建表格即可，不需要编程。

建议投入：约90—120分钟，可分两次完成

## 先理解：复核究竟要证明什么

NAV是一个结果，它依赖若干判断同时成立：交易和余额没有遗漏，价格与估值时点匹配，费用使用了有效条款，份额分母对应正确日期。重复服务商的加总可以发现计算错误，却不能单独验证这些条件。如果服务商和内部表格都使用过期价格，两份结果完全一致仍可能有错。

本项目把复核分为三个层次。第一层核实输入是否完整且适用；第二层重算金额并解释差异；第三层判断未结事项是否影响发布。三个层次需要不同证据。银行记录支持现金存在与时点，价格文件支持计价输入，参数批准记录支持费用口径，TA冻结名册支持份额。不能用一份服务商汇总表同时代替所有证据。

数学关系也要分开。净资产等于资产减负债，单位净值等于净资产除以份额；净资产变化还受投资者资金流入流出影响。本例没有申赎，因此净资产变动可以与当日损益直接勾稽。真实产品存在资本活动时，应另列资金与份额变动，不能把所有净资产变化解释为投资收益。

## 练习材料：先读取证据，再看草稿

虚构产品“教学基金A”，估值日为教学日T。资料包中的记录均在T日截止后冻结；E01至E07构成本练习已确认的完整总体，不存在未提供的其他资产或负债。这个设定仅用于让练习可解，真实工作中仍需用应收文件清单、账户清单和控制总数验证完整性。

债券以2,000张计，每张面值100元；表中净价98与全价99均按每100元面值报价。两者差额1元是每张应计利息，整笔应计利息2,000元。可以用净价加利息或直接用全价，不能两者同时加。

| 证据ID | T日已确认资料 | 用途 |
| --- | --- | --- |
| E01 | 银行现金100,000；与现金明细一致 | 现金余额与截止 |
| E02 | 股票10,000股；债券2,000张；与独立持仓记录一致 | 数量与资产总体 |

## 第一步：检查服务商草稿的内部关系

以下是待复核草稿，不是正确答案。先核对它自己的加总和除法是否成立，再与证据逐项比较。如果你直接把草稿金额复制进另一张表，即使公式全部正确，也只是复现了草稿使用的输入。

记录差异时使用一致方向：本项目定义“差异＝草稿－正确值”。这样正数表示草稿高估。份额属于分母差异，应单独列示，不能把少计的份额当作净资产金额扣除。草稿单位净值由400,700除以298,000得到，展示为1.344631；展示舍入不影响本项目对输入差异的判断。

| 另列债券应计利息 | 2,000 |
| 其他应收 | 500 |
| 应付费用 | 800 |
| 结算应付 | 20,000 |
| 净资产 | 400,700 |
| 确认份额 | 298,000 |

## 第二步：独立重算，并把差异对应到原因

从E02数量出发，分别与E03、E04的有效价格结合。股票使用T日价格；债券自行选择净价加利息或全价口径，在底稿标题中写清选择，并检查同一利息只出现一次。这里验证的是价格含义和计算，不能仅依赖服务商给出的“市值”列。

费用需要从期初滚到期末：期初应付加本期计提减本期支付。E06已经给出本练习有效参数下的当日计提，不需要再假定年费率。确认全部资产负债后，使用E07冻结份额计算单位净值。保留未舍入计算值，最后再按练习要求展示六位小数。

差异表至少应区分股票价格版本、债券利息重复、当日费用遗漏和份额版本四项。每项记录影响金额、证据、建议修正与复核状态。份额差异不会改变净资产，却会改变单位净值，因此“净资产已对平”不足以证明单位净值可靠。

请完成：完成正确净资产、单位净值与草稿净资产高估额。每个修正必须对应E01—E07之一。

## 第三步：用变动解释检验结果

T-1已确认数据为：现金100,000，股票119,000，债券净价金额195,000，应计利息1,800，其他应收0，应付费用800，结算应付20,000，份额300,000。T日没有资金或份额活动。先自行算出期初净资产，再按科目解释其如何变到期末。

将股票价格变动、债券净价变动、债券应计利息、其他应收增加及费用计提分别列示。应收增加在本例中被设定为已确认的当日收益；真实业务需要检查其性质，不能把任何应收增加都自动归为收入。变动解释的总额应与期末减期初净资产一致。

桥接能够帮助定位遗漏，但不能代替独立证据。一笔资产高估与一笔负债高估可能互相抵消，净资产桥接仍能对平。所以复核结论需要保留逐项检查，不能用总体净资产一致来豁免现金、负债和份额的异常。

请完成：完成期初→收益与费用→期末的桥接，并解释为什么金额对平仍不足以单独支持发布。

## 异常挑战：数值正确之后，还缺什么

挑战一：服务商接受你的计算，但尚未发送更正版。你能否把草稿标为可发布？应区分“拟更正值已计算”和“正式输出已更正并按适用流程复核”。需要取得最终文件、核对版本、完成相应确认和批准，避免发布的仍是旧草稿。

挑战二：T+1结算应付20,000以现金支付，其他项目不变。分别写出支付后的现金、结算应付和净资产。这个练习检验你能否区分资产负债同时减少与当期损益；支付并不自动产生第二次费用。

挑战三：E03有效价格文件缺失，只剩服务商和内部系统都为12.00。两个结果相同能否关闭价格核验？本练习的数值答案仍可作为已给定数据下的计算，但真实发布判断必须增加“有效价格证据未取得”的限制，按既定异常流程补证与升级。

## 交付要求：让下一位复核人能够重现判断

底稿应保存输入来源、金额公式、净资产差异表、份额差异、变动桥接和未结事项。发布意见要明确当前状态、哪些修正尚待落实、由谁完成后续确认，以及复核结论对应哪个版本。它不是一句无条件的“已核对无误”。

计算检查可以自动完成，发布判断则不能只靠数字打勾。本项目的教学验收要求是：计算吻合、四类差异说明充分、证据引用可追溯、异常状态不被隐去，并且未把教学结论当作真实业务授权。

## 验收标准

- 使用独立证据检查数量、时点和价格定义
- 找出三项净资产差异及一项份额差异
- 净资产、单位净值和期间桥接分别成立
- 保留未结事项，不以算对数字替代发布批准
