# 动手项目

全部使用虚构教学材料。先独立完成底稿，再对照参考成果。所有日期、金额与门槛均需按项目说明理解。

- [做一份能够解释的 NAV 复核底稿](nav-review.md)：一份NAV重算表、一张差异登记表、一段发布前复核意见。 约90—120分钟，可分两次完成。
- [建立一份可执行的报送义务清单与日历](reporting-calendar.md)：一份义务台账、一张含内部里程碑的日历、一份异常与回执记录。 约90分钟。
- [设计并评估一次 redo 改善试点](redo-pilot.md)：一份试点章程、一张风险—控制—测试矩阵、一份包含停止条件的评估意见。 约120分钟，可分两次完成。

离线HTML支持项目笔记、数值或日期检查，以及单独的项目记录备份。
